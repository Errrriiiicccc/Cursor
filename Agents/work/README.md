# Work records

Each workstream gets one folder: `Agents/work/<date>-<short-name>/`.

Example: `Agents/work/2026-09-19-slice-1-agents/`.

Keep the record set small. Start with the files below. Add another file only when a role must produce it.

| File | Who writes it | What it is |
| --- | --- | --- |
| `state.md` | Coordinator | Current state, next role, disposition |
| `request.md` | Coordinator | Owner request, copied or summarized |
| `specification.md` | Analyst | Authorized intent |
| `plan.md` | Planner | Steps and task contracts |
| `findings.md` | Owner Advocate | Severity-ranked critique |
| `implementation.md` | Agent Creator or later specialist | What changed |
| `efficiency.md` | Coordinator | Compact process history |

Do not store chat transcripts here.
